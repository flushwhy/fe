The toolbox

Find your next command.

Search by command, task, or tool. Your local fe --help is always the source of truth for the version you have installed.

fe init

Create a project from a language default or named template.

fe template list

List available remote project templates.

fe template update <template-id>

Refresh a named template in the local cache.

fe setup

Prepare project tooling and dependencies where supported by the project configuration.

fe build

Run configured build targets, optionally selecting a platform.

fe watch

Watch supported project files and run the configured development steps.

fe godot

Godot discovery, diagnostics, export, and native extension helpers.

fe export

Export configured Godot presets and inspect expected output paths.

fe o3de

Discover and manage O3DE projects, engines, gems, and build workflows.

fe blender

Support Blender add-on project workflows.

fe pack

Pack source sprites into configured sprite sheets.

fe transcode

Convert audio and video through FFmpeg, including game-friendly MP4 and WebM defaults.

fe install

Install supported development tools and libraries.

fe add

Add supported project dependencies or integrations.

fe check [path]

Run available static analyzers for supported languages and explain missing tools.

fe doctor

Diagnose local toolchain and project configuration issues.

fe validate

Check project configuration and paths before running a workflow.

fe manifest

Write an artifact inventory with SHA-256 checksums and build metadata.

fe changelog

Generate Markdown release notes from Git history and tags.

fe package

Create portable ZIP or TAR.GZ archives from build artifacts.

fe release --dry-run

Preview the release plan without running its side effects.

fe release

Run the configured build, packaging, and publishing workflow.

fe bmp

Push builds to itch.io through Butler.

fe tui

Open the local interactive terminal interface.

fe update

Check for and apply updates using the supported installation method.
